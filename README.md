# 啾讯 · 发布产物

「啾讯 · 观鸟地区稀有鸟种榜」的**发布产物**仓库（源码仓库为私有，不含源码）。

- 每次发版，CI 会把同一批产物镜像到这里：`…-win-x64.zip` / `…-mac-arm64.zip` / `…-mac-x64.zip` / `…-android-arm64.apk`
- 应用内「我的 → 检查更新」读的就是这里的 `releases/latest`

> 为什么需要这个仓库：GitHub 对**私有**仓库的 Release 匿名访问一律返回 404，
> 而应用里的版本检查是匿名请求（APK 里没有、也不能有 token）。所以源码私有、
> 产物放这里公开，两边各得其所。
